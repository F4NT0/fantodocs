All the shortcuts below are configured in the [F4NT0/nvim](https://github.com/F4NT0/nvim) repository.

The `<leader>` key is mapped to <Kbd windows="Space" />, so `Space H S` means pressing **Space**, then **H**, then **S**, one key at a time.

Inside Neovim itself you can see this list with the `:Khelp` command.

## Global shortcuts

Shortcuts that do not belong to a specific plugin: window navigation, resizing, and visual editing.

- **Configuration:** [`lua/config/keymaps.lua`](https://github.com/F4NT0/nvim/blob/main/lua/config/keymaps.lua)

| Command | Description |
| --- | --- |
| <Kbd windows="Esc" /> | Clears the highlight from the last search |
| <Kbd windows="Ctrl+H" /> | Moves the cursor to the left window |
| <Kbd windows="Ctrl+J" /> | Moves the cursor to the window below |
| <Kbd windows="Ctrl+K" /> | Moves the cursor to the window above |
| <Kbd windows="Ctrl+Right" /> | Increases the window width |
| <Kbd windows="Ctrl+Left" /> | Decreases the window width |
| <Kbd windows="Ctrl+Up" /> | Increases the window height |
| <Kbd windows="Ctrl+Down" /> | Decreases the window height |
| <Kbd windows=">" /> (visual mode) | Indents while keeping the selection |
| <Kbd windows="<" /> (visual mode) | Removes indentation while keeping the selection |
| <Kbd windows="J" /> (visual mode) | Moves the selected lines down |
| <Kbd windows="K" /> (visual mode) | Moves the selected lines up |

## Barbar

Tab bar for open buffers, with pinned tabs and quick navigation.

- **Plugin:** [romgrk/barbar.nvim](https://github.com/romgrk/barbar.nvim)
- **Configuration:** [`lua/plugins/interface/barbar.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/interface/barbar.lua) and the shortcuts in [`lua/config/keymaps.lua`](https://github.com/F4NT0/nvim/blob/main/lua/config/keymaps.lua)

| Command | Description |
| --- | --- |
| <Kbd windows="Alt+," /> | Goes to the previous tab |
| <Kbd windows="Alt+." /> | Goes to the next tab |
| <Kbd windows="Alt+<" /> | Moves the current tab one position to the left |
| <Kbd windows="Alt+>" /> | Moves the current tab one position to the right |
| <Kbd windows="Alt+1" /> to <Kbd windows="Alt+6" /> | Jumps straight to tab 1 through 6 |
| <Kbd windows="Alt+P" /> | Pins the current tab |
| <Kbd windows="Alt+C" /> | Closes the current tab |

## nvim-surround

Adds, removes, and changes delimiters (parentheses, quotes, HTML tags) around text.

- **Plugin:** [kylechui/nvim-surround](https://github.com/kylechui/nvim-surround)
- **Configuration:** [`lua/plugins/programming/nvim-surround.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/programming/nvim-surround.lua)

| Command | Description |
| --- | --- |
| <Kbd windows="y s i w )" /> | Wraps the word in parentheses: `word` becomes `(word)` |
| <Kbd windows='y s $ "' /> | Wraps text in quotes until the end of the line: `some text` becomes `"some text"` |
| <Kbd windows="d s ]" /> | Removes the surrounding brackets: `[delete]` becomes `delete` |
| <Kbd windows="d s t" /> | Removes the HTML tag around the text |
| <Kbd windows="d s f" /> | Removes the surrounding function call: `call(arg)` becomes `arg` |
| <Kbd windows={"c s ' \""} /> | Changes single quotes to double quotes: `'word'` becomes `"word"` |
| <Kbd windows="c s t h 1 Enter" /> | Changes the HTML tag to an `h1` |

## Gitsigns

Shows Git changes in the side of the file and lets you work with each changed chunk (hunk).

- **Plugin:** [lewis6991/gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)
- **Configuration:** [`lua/plugins/git-manager/gitsigns.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/git-manager/gitsigns.lua)

| Command | Description |
| --- | --- |
| <Kbd windows="Space H S" /> | Stages the current hunk |
| <Kbd windows="Space H R" /> | Resets the current hunk |
| <Kbd windows="Space H Shift+S" /> | Stages all hunks in the file |
| <Kbd windows="Space H Shift+R" /> | Resets all hunks in the file |
| <Kbd windows="Space H P" /> | Shows a preview of the hunk under the cursor |
| <Kbd windows="Space H B" /> | Shows the author of the current line (blame) |
| <Kbd windows="] c" /> | Goes to the next changed hunk |
| <Kbd windows="[ c" /> | Goes to the previous changed hunk |

| Command | Description |
| --- | --- |
| <Kbd windows="Space C H" /> | Shows the documentation under the cursor (hover) |
| <Kbd windows="Space C D" /> | Goes to the definition |
| <Kbd windows="Space C Shift+D" /> | Goes to the declaration |
| <Kbd windows="Space C R" /> | Lists the references |
| <Kbd windows="Space C I" /> | Lists the implementations |
| <Kbd windows="Space C Shift+R" /> | Renames the symbol |
| <Kbd windows="Space C A" /> | Shows the available code actions |
| <Kbd windows="Space C F" /> | Formats the current file |
| <Kbd windows="Space S D" /> | Shows the diagnostic under the cursor |
| <Kbd windows="Space D L" /> | Sends all diagnostics to the location list |
