## What is clidocs

**clidocs** is a terminal-native snippet manager built with **Go** and the Bubble Tea framework. It organizes code snippets, notes and reference material without ever leaving the command line.

The interface has three panels, fully keyboard-driven:

- **Folders:** categories and subfolders for your snippets.
- **Snippets:** the files in the selected folder.
- **Preview:** content with syntax highlighting (GitHub Dark theme).

## Main features

- Create, rename, move and delete folders and files.
- Real-time search across folders, files and inside the preview.
- Open files in Neovim or VS Code.
- Favorite folders and import files from anywhere.
- Sync your snippets to a GitHub repository.
- Built-in console (`:`) with commands such as `time`, `whoami` and `nvim`.
