# Using Asides

Asides is a component we can use to create custom notes.

I use Asides to present important information.

## Importing Asides in the mdx file
<br></br>

After the frontmatter of the mdx file, add the following import:

```js
import { Aside } from '@astrojs/starlight/components';
```

## Adding code

<br></br>

We can add code and other markdown details inside an Aside.

<Aside type="caution" title="Attention!">
  We can add code and other details using the following structure:

  ```js
  import { Aside } from '@astrojs/starlight/components';  
  ```

  We can also `highlight` a piece of information. 

  We can add [Links]() and <span style="color: red">Highlight</span> information.
</Aside>

```js
<Aside type="caution" title="Attention!">
  We can add code and other details using the following structure:
