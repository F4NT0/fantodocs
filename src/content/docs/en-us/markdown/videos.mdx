## How to add videos to the site

- Import the `VideoPlayer` component in your page:

```js
import { VideoPlayer } from 'starlight-videos/components'
```

- Add the video to the site:

<VideoPlayer link="https://youtu.be/zwxll667cwM"/>

- This is the tag to add a standalone video like this:

```js
<VideoPlayer link="https://youtu.be/zwxll667cwM"/>
```
