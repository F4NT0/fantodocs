## Under the hood

<br></br>

The .NET platform is built on a _runtime_ called the <span style="color: lightgreen">CLR</span> (<span style="color: lightgreen">C</span>ommon <span style="color: lightgreen">L</span>anguage <span style="color: lightgreen">R</span>untime), which executes code compiled to <span style="color: lightgreen">IL</span> (<span style="color: lightgreen">I</span>ntermediate <span style="color: lightgreen">L</span>anguage) and manages all the details the application needs, such as memory, security, exceptions, etc.
