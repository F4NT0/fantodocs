# What is a console project

Console projects are simple .NET projects used to create examples or small pieces of code to validate some piece of information or need.

We can create as many console projects as we like, and they are quite simple. I will explain each file and what it is for.

## Creating a console project using the .NET CLI

If you have the .NET compiler installed on your computer, you can create a project straight from your console. First, check which version of .NET you have installed.

```bash title="Checking the .NET version in the terminal"
dotnet --version
```

Now we can create an initial project template with the following command, and I will show the generated files:

```bash title="Creating a console project called MyApp"
dotnet new console -n MyApp
```

When we run this command, it creates the following files in a directory:

<FileTree>

- MyApp/
    - MyApp.csproj
    - Program.cs
    - appsettings.Development.json
    - appsettings.json

</FileTree>

A short description of each file:

- <span style="color: orange">MyApp.csproj</span>
    - XML file
    - Defines which files are part of the build
    - Manages dependencies (NuGet packages, references, etc.)
    - Configures the build (.NET version, output type, etc.)
    - Integrates with tools (dotnet CLI)
    - NOTE: without this file, .NET would not know how to build or run the project.
- <span style="color: orange">Program.cs</span>
    - C# file with the startup code of our project, including Main().
    - This is the entry point for our project's configuration. We can create multiple C# files with whatever we need and connect them in this file so they start when the project starts.
- <span style="color: orange">appsettings.json</span>
    - A JSON file holding the necessary settings in a structured way.
    - Used for RabbitMQ settings, logs, database connections, etc.
    - Contains all the settings needed for external projects or programs the application depends on.
