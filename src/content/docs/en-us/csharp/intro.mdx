# What is C#?

<span style="color: magenta">C#</span> (pronounced _C Sharp_) is a modern, object-oriented, strongly typed programming language. 

It was developed by Microsoft in 2000 as part of the <span style="color: magenta">.NET</span> platform.

It is used for Desktop, Web, and Mobile apps, Games, Scripts, Cloud services, and more.

It is one of the most popular languages in the corporate world and among developers who work with Microsoft software.

## Main features

<br></br>
&#8594; <span style="color: orange">Object orientation</span> : Supports inheritance, polymorphism, and encapsulation.

&#8594; <span style="color: orange">Familiar syntax</span> : Similar to Java and C++. 

&#8594; <span style="color: orange">Garbage Collection</span> : Automatic memory management.

&#8594; <span style="color: orange">Cross-platform</span> : Since .NET Core, C# can be used on Windows, Linux, and macOS; the .NET Framework is only compatible with Windows.

&#8594; <span style="color: orange">Type safety</span> : A strongly typed language means the type of data being used (string, int, float, etc.) must be explicit, which gives us control over the data flow in our system.

&#8594; <span style="color: orange">LINQ</span> : Querying databases and collections directly from the language, one of the differentiators of C#.

&#8594; <span style="color: orange">Async/Await</span> : Native support for asynchronous programming.

## Version history

<br></br>

|Version|Release year|Key features|
|---|---|---|
|C# 1.0|2002|First version|
|C# 2.0|2005|Generics, Anonymous Methods|
|C# 3.0|2007|LINQ, Lambda Expressions|
|C# 4.0|2010|dynamic, optional arguments|
|C# 5.0|2012|async/await|
|C# 6.0|2015|String interpolation|
|C# 7.0|2017|Tuples, patterns|
|C# 8.0|2019|Nullable reference types, ranges|
|C# 9.0|2020|record, init-only setters|
|C# 10.0|2021|Global using, file-scoped namespace|
|C# 11.0|2022|raw string literals, generic attributes|
|C# 12.0|2023|Primary constructors, collection expressions|
|C# 13.0|2024|params with collections, structs in interfaces|
