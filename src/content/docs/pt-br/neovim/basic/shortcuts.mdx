Todos os atalhos abaixo estão configurados no repositório [F4NT0/nvim](https://github.com/F4NT0/nvim).

A tecla `<leader>` está mapeada para <Kbd windows="Space" />, então `Space H S` significa apertar **Space**, depois **H** e depois **S**, uma tecla de cada vez.

Dentro do próprio Neovim você pode ver esta lista com o comando `:Khelp`.

## Atalhos globais

Atalhos que não pertencem a um plugin específico: navegação entre janelas, redimensionamento e edição visual.

- **Configuração:** [`lua/config/keymaps.lua`](https://github.com/F4NT0/nvim/blob/main/lua/config/keymaps.lua)

| Comando | Descrição |
| --- | --- |
| <Kbd windows="Esc" /> | Remove o destaque da última busca |
| <Kbd windows="Ctrl+H" /> | Move o cursor para a janela da esquerda |
| <Kbd windows="Ctrl+J" /> | Move o cursor para a janela de baixo |
| <Kbd windows="Ctrl+K" /> | Move o cursor para a janela de cima |
| <Kbd windows="Ctrl+Right" /> | Aumenta a largura da janela |
| <Kbd windows="Ctrl+Left" /> | Diminui a largura da janela |
| <Kbd windows="Ctrl+Up" /> | Aumenta a altura da janela |
| <Kbd windows="Ctrl+Down" /> | Diminui a altura da janela |
| <Kbd windows=">" /> (modo visual) | Indenta mantendo a seleção |
| <Kbd windows="<" /> (modo visual) | Remove a indentação mantendo a seleção |
| <Kbd windows="J" /> (modo visual) | Move as linhas selecionadas para baixo |
| <Kbd windows="K" /> (modo visual) | Move as linhas selecionadas para cima |

## Barbar

Barra de abas para os buffers abertos, com abas fixas e navegação rápida.

- **Plugin:** [romgrk/barbar.nvim](https://github.com/romgrk/barbar.nvim)
- **Configuração:** [`lua/plugins/interface/barbar.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/interface/barbar.lua) e os atalhos em [`lua/config/keymaps.lua`](https://github.com/F4NT0/nvim/blob/main/lua/config/keymaps.lua)

| Comando | Descrição |
| --- | --- |
| <Kbd windows="Alt+," /> | Vai para a aba anterior |
| <Kbd windows="Alt+." /> | Vai para a próxima aba |
| <Kbd windows="Alt+<" /> | Move a aba atual uma posição para a esquerda |
| <Kbd windows="Alt+>" /> | Move a aba atual uma posição para a direita |
| <Kbd windows="Alt+1" /> até <Kbd windows="Alt+6" /> | Vai direto para a aba de 1 a 6 |
| <Kbd windows="Alt+P" /> | Fixa a aba atual |
| <Kbd windows="Alt+C" /> | Fecha a aba atual |

## nvim-surround

Adiciona, remove e troca delimitadores (parênteses, aspas, tags HTML) ao redor de um texto.

- **Plugin:** [kylechui/nvim-surround](https://github.com/kylechui/nvim-surround)
- **Configuração:** [`lua/plugins/programming/nvim-surround.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/programming/nvim-surround.lua)

| Comando | Descrição |
| --- | --- |
| <Kbd windows="y s i w )" /> | Coloca parênteses em volta da palavra: `word` vira `(word)` |
| <Kbd windows='y s $ "' /> | Coloca aspas até o fim da linha: `some text` vira `"some text"` |
| <Kbd windows="d s ]" /> | Remove os colchetes ao redor: `[delete]` vira `delete` |
| <Kbd windows="d s t" /> | Remove a tag HTML ao redor do texto |
| <Kbd windows="d s f" /> | Remove a chamada de função ao redor: `call(arg)` vira `arg` |
| <Kbd windows={"c s ' \""} /> | Troca aspas simples por duplas: `'word'` vira `"word"` |
| <Kbd windows="c s t h 1 Enter" /> | Troca a tag HTML por um `h1` |

## Gitsigns

Mostra as alterações do Git na lateral do arquivo e permite trabalhar com cada trecho alterado (hunk).

- **Plugin:** [lewis6991/gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim)
- **Configuração:** [`lua/plugins/git-manager/gitsigns.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/git-manager/gitsigns.lua)

| Comando | Descrição |
| --- | --- |
| <Kbd windows="Space H S" /> | Adiciona o trecho atual ao stage |
| <Kbd windows="Space H R" /> | Desfaz as alterações do trecho atual |
| <Kbd windows="Space H Shift+S" /> | Adiciona todos os trechos do arquivo ao stage |
| <Kbd windows="Space H Shift+R" /> | Desfaz as alterações de todos os trechos do arquivo |
| <Kbd windows="Space H P" /> | Mostra uma prévia do trecho sob o cursor |
| <Kbd windows="Space H B" /> | Mostra o autor da linha atual (blame) |
| <Kbd windows="] c" /> | Vai para o próximo trecho alterado |
| <Kbd windows="[ c" /> | Vai para o trecho alterado anterior |

| <Kbd windows="Space C D" /> | Vai para a definição |
| <Kbd windows="Space C Shift+D" /> | Vai para a declaração |
| <Kbd windows="Space C R" /> | Lista as referências |
| <Kbd windows="Space C I" /> | Lista as implementações |
| <Kbd windows="Space C Shift+R" /> | Renomeia o símbolo |

- **Configuração:** [`lua/plugins/lsp/nvim-dap.lua`](https://github.com/F4NT0/nvim/blob/main/lua/plugins/lsp/nvim-dap.lua)

| Comando | Descrição |
| --- | --- |
| <Kbd windows="Space D T" /> | Liga ou desliga um breakpoint |
| <Kbd windows="Space D S" /> | Inicia a sessão ou continua a execução |
| <Kbd windows="Space D C" /> | Fecha os painéis do dap-ui |
| <Kbd windows="Space D O" /> | Executa a linha e passa por cima de funções (step over) |
